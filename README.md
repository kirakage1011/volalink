# ボラリンク（仮） PWA試作品

## 含まれる機能
- ホーム／募集検索／募集詳細／お気に入り／マイページ
- 活動分野・日付・時間帯の絞り込み
- お気に入り・試作品内の申し込み記録（ブラウザ内に保存）
- PWA manifest と Service Worker による基本的なオフラインキャッシュ

## 起動方法
1. ZIPを展開する
2. フォルダでターミナルを開く
3. `python3 -m http.server 8000` を実行
4. ブラウザで `http://localhost:8000` を開く

`file://` で直接開くとService Workerは動作しません。PWAとして配信・インストールするにはHTTPSで公開してください。

## 重要な制限
これは画面・操作確認用のフロントエンド試作品です。募集データは架空のサンプルで、申し込みは実在の団体に送信されません。ログイン、データベース、団体審査、保護者同意の確認、実際のポイント付与、通知、管理者画面、セキュリティ対策は未実装です。実運用前にバックエンド、認証、アクセス制御、個人情報保護、未成年者の安全対策を設計・検証してください。
